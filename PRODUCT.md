# Product truth

A local reproduction of the captured Nothin’ studio website, with 25 documents and their original public artwork, typography and animation. The current user is customizing this replica's images, copy and spacing through a Chinese editor.

Required editing: upload single or multiple images; change text, font, font size, weight, line height, letter spacing, alignment and color; adjust margins, padding, container gaps and independent blank spacers through numeric fields and direct page drag handles; preview normal page interactions; undo, restore and back up edits.

Keep the reference composition and motion until a user edits that element. Text edits are plain text. Uploaded images and configuration stay in browser IndexedDB at the current origin; there is no backend, cloud sync, authentication or source-file rewrite. JSON export/import transfers the whole draft. DOM text and img nodes are editable; video content and SVG logo paths are outside this editor's scope.

## Local extension contract

THESIS: directly select and customize real page content, then preview the result.
OWN-WORLD: inherit the original black/white PP typography and public artwork; a quiet, isolated inspector supplies Chinese labelled controls.
STORY: select → adjust → preview, with local autosave, undo/reset and JSON backup.
FIRST VIEWPORT: original composition remains visible; the fixed right inspector can collapse into a small launcher.
FORM: compact numeric fields, text/image controls, explicit layout scopes and internal scrolling; narrow-screen adaptation keeps actions reachable.
